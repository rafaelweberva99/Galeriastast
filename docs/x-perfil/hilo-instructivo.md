# Hilo instructivo: cómo cargar tus partidos

Publica el post 1 y responde cada post al anterior para armar el hilo. Ninguno pasa de 280 caracteres.

## Post 1

```
¿Cómo cargar tus partidos en Galucha? 🧵

Tienes 3 formas: con una foto de tus entradas, con tu Excel o marcándolos a mano.

Te explico paso a paso 👇
#CabalaOYeta
```

## Post 2

```
📸 Opción 1: con una foto de tus entradas

1. Abre PuntoTicket o la ticketera de tu club y entra a tu historial de compras
2. Toma una captura de pantalla
3. En Galucha entra a "Importar entradas" y súbelas

También sirve el PDF de la entrada o el correo de compra.
```

## Post 3

```
📊 Opción 2: con tu Excel

¿Anotas tus partidos en Excel o Google Sheets?

1. Selecciona tus filas, con el encabezado, y cópialas
2. En "Importar entradas", pégalas en "¿Llevas tus partidos en un Excel?"
3. Toca "Buscar mis partidos"

También puedes subir un archivo CSV.
```

## Post 4

```
¿Qué necesita tu Excel?

Cada fila debe tener la fecha del partido, o el año con el rival y el resultado. Las columnas pueden ir en cualquier orden.

Ejemplo:
Fecha | Local | Resultado | Visita
10-08-2024 | U. de Chile | 0-0 | Colo-Colo
```

## Post 5

```
✅ Revisa y confirma

Galucha te muestra los partidos que encontró. Tú eliges cuáles son tuyos y tu efectividad se calcula al tiro.

¿Te faltó alguno? Opción 3: búscalo en "Marcar partidos" y márcalo a mano.
```
